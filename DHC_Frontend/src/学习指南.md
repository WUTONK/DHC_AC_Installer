# DHC Frontend 学习指南

## 🎯 目标

理解这个 Electron + React 应用的架构和代码，让你真正掌握它，而不是只是"能用"。

## 📚 学习路径

### 第一阶段：理解 Electron 基础概念（1-2 小时）

**必读文档**：
- [Electron 官方文档 - 主进程和渲染进程](https://www.electronjs.org/docs/latest/tutorial/process-model)
- [IPC 通信基础](https://www.electronjs.org/docs/latest/tutorial/ipc)

**核心概念**：
1. **主进程（Main Process）**：`src/main/index.ts`
   - 应用入口
   - 创建和管理窗口
   - 可以访问所有 Node.js API

2. **渲染进程（Renderer Process）**：`src/renderer/src/`
   - 显示 UI（React 代码）
   - 运行在浏览器环境中
   - 不能直接访问 Node.js API

3. **IPC 通信**：主进程和渲染进程通信的方式
   - 主进程：`ipcMain.handle()` 接收消息
   - 渲染进程：`ipcRenderer.invoke()` 发送消息

### 第二阶段：理解项目架构（2-3 小时）

**阅读顺序**：
1. `src/main/README.md` - 理解主进程
2. `src/preload/README.md` - 理解预加载脚本
3. `src/shared/README.md` - 理解 API 客户端

**关键问题**：
- [ ] 应用启动时发生了什么？
- [ ] 窗口是如何创建的？
- [ ] React 代码如何调用后端 API？
- [ ] 数据是如何在主进程和渲染进程之间传递的？

### 第三阶段：理解数据流（1-2 小时）

**完整的数据流**：

```
用户点击按钮（React 组件）
  ↓
调用 Api.getServerInfo()（shared/index.ts）
  ↓
ipcFetch() 调用 window.api.requestApi(url)（shared/index.ts）
  ↓
ipcRenderer.invoke('api-request', url)（preload/index.ts）
  ↓
IPC 消息发送到主进程
  ↓
ipcMain.handle('api-request', ...) 接收（main/index.ts）
  ↓
主进程发送 HTTP 请求到后端（fetch(url)）
  ↓
后端返回数据
  ↓
主进程通过 IPC 返回结果
  ↓
渲染进程收到结果
  ↓
ipcFetch 包装成 Response 对象
  ↓
API 客户端解析数据
  ↓
React 组件更新 UI
```

**练习**：
1. 在代码中添加 `console.log`，跟踪一次 API 调用的完整流程
2. 画一个架构图，标注每个文件的作用

### 第四阶段：动手实验（2-3 小时）

**实验1：修改窗口大小**
- 找到 `createWindow()` 函数
- 修改 `windowWidth` 和 `windowHeight`
- 运行应用，观察变化

**实验2：添加新的 IPC 通信**
- 在主进程添加新的 `ipcMain.handle`
- 在 preload 脚本暴露新的 API
- 在 React 组件中调用

**实验3：理解后端通信**
- 查看后端代码（DHC_Backend）
- 理解后端提供了哪些 API
- 理解前端如何调用这些 API

### 第五阶段：深入理解 React 部分（按需）

**关键文件**：
- `src/renderer/src/App.tsx` - 主应用组件
- `src/renderer/src/main.tsx` - React 入口
- `src/renderer/src/components/` - 组件库

**学习重点**：
- React Hooks（useState, useEffect）
- Context API（DevModeContext, NavigationContext）
- 组件通信和状态管理

## 🛠️ 实用技巧

### 1. 调试技巧

**主进程调试**：
```typescript
console.log('主进程日志')  // 在终端查看
```

**渲染进程调试**：
```typescript
console.log('渲染进程日志')  // 在 DevTools 查看（F12）
```

**IPC 通信调试**：
在主进程和 preload 脚本中添加日志：
```typescript
// main/index.ts
ipcMain.handle('api-request', async (_, url) => {
  console.log('主进程收到 IPC 请求:', url)
  // ...
})

// preload/index.ts
const api = {
  requestApi: (url: string) => {
    console.log('Preload 收到请求:', url)
    return ipcRenderer.invoke('api-request', url)
  }
}
```

### 2. 理解代码的方法

1. **从入口开始**：找到应用启动的地方，逐步跟踪
2. **画流程图**：用纸笔画出数据流和调用链
3. **添加注释**：在代码中添加自己的理解
4. **修改实验**：小改动，看效果，加深理解

### 3. 常见困惑解答

**Q: 为什么代码这么复杂？**
A: Electron 的安全模型要求主进程和渲染进程分离，所以需要 IPC 通信。这是必要的复杂性。

**Q: 我可以简化代码吗？**
A: 可以，但要注意安全性。比如关闭 `contextIsolation` 会让代码更简单，但安全性降低。

**Q: 如何学习 Electron？**
A: 
1. 先理解基础概念（主进程、渲染进程、IPC）
2. 跟着官方教程做一个简单应用
3. 阅读现有项目的代码
4. 动手修改和实验
